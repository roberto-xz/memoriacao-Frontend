# 🏛️ MemoriAção

Uma plataforma digital interativa para preservação, exploração e valorização da memória institucional por meio de experiências imersivas e conteúdo estruturado.

---

## 📖 Sobre o Projeto

O **MemoriAção** é uma iniciativa que combina tecnologia web e memória histórica para criar um ambiente virtual onde usuários podem explorar espaços, conhecer histórias e acessar conteúdos institucionais de forma dinâmica.

A proposta vai além de um repositório estático: o sistema busca transformar informação em experiência, utilizando recursos visuais, navegação interativa e organização estruturada do conteúdo.

---

## 💡 Inovação

O projeto se destaca por integrar:

* Navegação baseada em mapa interativo
* Visualização de ambientes em 360°
* Visualização de produções internas em VR e AR°
* Estrutura modular de conteúdo (entrevistas,depoimentos, histórias, etc.. )
* Experiência híbrida entre site institucional e ambiente explorável

A inovação está na forma como a memória é apresentada: não apenas como texto, mas como **ambiente navegável e contextualizado**.

---

## 🧠 Objetivo

* Preservar a memória institucional
* Facilitar o acesso à informação histórica
* Engajar alunos e comunidade
* Criar uma experiência digital interativa

---

## 🖥️ Tecnologias Utilizadas

* **Frontend:** Vite+vue3 + Typescritp
* **backend:** sql.js-httpvfs / Supabase
* **Renderização 3D/360°/AR/VR:**  A-Frame/Three.js
* **Estilização:** CSS moderno
* **Deploy:** GitHub Pages + GitHub Actions
* **Versionamento:** Git
